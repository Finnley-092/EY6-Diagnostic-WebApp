Systemhinweis

Bluetooth benötigt eine sichere Verbindung (HTTPS) und eine Browser-Unterstützung für Web Bluetooth. Auf iPhone/iPad funktioniert es in Safari normalerweise nicht; nutze einen kompatiblen Browser bzw. Bluefy, falls dort Web Bluetooth unterstützt wird.

Wichtig zum Tuning: Die Suite liest und zeichnet auf. Im Controller-Link kann sie zusätzlich eine bereits bekannte Basisdaten-Abfrage senden; unbekannte Controller-Befehle bleiben gesperrt. Ein BLE-Scan kann nur Daten erfassen, die das Dashboard bzw. der Controller tatsächlich über Bluetooth freigibt. Interne Controller-Register oder Firmware lassen sich damit nicht automatisch vollständig auslesen.
